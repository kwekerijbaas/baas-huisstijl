# Claude Code — Kwekerij Baas

Volg de centrale richtlijnen in @docs/ai-coding-guidelines.md.

## Aanvullend voor Claude Code

- Communicatie in deze sessie: **Nederlands**.
- Lees vóór je begint: `README.md`, `docs/runbook.md` (indien aanwezig) en recente ADR's in `docs/adr/`.
- Bevestig kort domein, applicatie en fase voordat je niet-triviale wijzigingen maakt.
- Stel bij grotere wijzigingen eerst een korte aanpak voor en wacht op bevestiging.
- Werk in kleine, testbare stappen; commit per logische eenheid.
- Sluit elke taak af met: wat is gedaan, wat is niet gedaan, vervolgvoorstel.
