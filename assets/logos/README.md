- `logo-01.png` — variant 01, voorkeur, op wit.
- `logo-02-dia-pos.png` — variant 02, dia positief, op `lime-groen`.
- `logo-03-excl-payoff.png` — variant 03, zonder pay-off.
- `logo-04-excl-payoff-dia-pos.png` — variant 04, zonder pay-off, dia positief.
- `logo-02-black.png`, `logo-02-black-zonder-payoff.png` — zwart, als kleur geen optie is.
